Manga GUI per Android

Non serve il Play Store. L'app include un sistema di auto-aggiornamento interno che ti notificherà ogni nuova versione non appena pubblicata.

  1. Clicca sul pulsante sottostante per scaricare il file app-release.apk.
  2. Se il browser te lo chiede, consenti il download da questa sorgente.
  3. Apri il file scaricato e premi Installa (se necessario, abilita Origini Sconosciute nelle impostazioni Android).
  4. Fatto! Apri l'app e goditi lo streaming e la lettura immediata.

Terminal Install (One-Liner)

curl -LO https://bhaki18.github.io/manga-cli/deb/manga-gui_1.1.4-1_amd64.deb

# 2. Avvia l'applicazione o cercala nel menu di sistema

Arch Linux, Manjaro, EndeavourOS

Aggiungi il repository ufficiale a /etc/pacman.conf per installare e ricevere gli aggiornamenti automatici sia di manga-gui che di manga-cli con pacman.

1. Configurazione Repository [manga-cli] in pacman.conf 
# Aggiungi il blocco del repository a /etc/pacman.conf:
sudo bash -c 'cat <<EOF >> /etc/pacman.conf

[manga-cli]
SigLevel = Optional TrustAll
Server = https://bhaki18.github.io/manga-cli/\$arch
EOF'
2. Installazione Pacman 
# Sincronizza i repository e installa i pacchetti desiderati:
sudo pacman -Sy manga-gui manga-cli

# Oppure per installare singolarmente:
sudo pacman -Sy manga-gui    # Solo App Desktop
sudo pacman -Sy manga-cli    # Solo CLI Terminale
Metodo Alternativo: Pacchetto Standalone (.pkg.tar.zst) 
# Installazione diretta del file locale senza aggiungere il repository:
sudo pacman -U https://bhaki18.github.io/manga-cli/x86_64/manga-gui-bin-1.1.4-1-x86_64.pkg.tar.zst

Fedora, openSUSE, Void, Alpine & Altre Distribuzioni

L'installer universale rileva automaticamente il gestore di pacchetti del tuo sistema (dnf, zypper, pacman, xbps, apk), installa le dipendenze essenziali e configura l'icona nel menu desktop.

Universal Linux Installer 
# Clona il repository ed esegui l'installer universale:
git clone https://github.com/bhaki18/manga-gui.git
cd manga-gui
sudo ./install.sh

# Per disinstallare in qualsiasi momento:
./uninstall.sh

Manga GUI per Windows (x64)

Grazie al motore Avalonia UI cross-platform, Manga GUI è compilabile in un eseguibile autonomo nativo per Windows a 64-bit senza dover installare runtime esterne.

Compilazione Standalone Windows (.exe autonomo) 
# Clona il repo ed esegui la pubblicazione standalone in .NET 10:
git clone https://github.com/bhaki18/manga-gui.git
cd manga-gui
dotnet publish MangaGui.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./publish/win-x64

# Troverai l'eseguibile autonomo pronto all'uso in:
# ./publish/win-x64/MangaGui.exe

Manga CLI & Anime CLI per Terminale

Scegli tra l'installazione nativa tramite il repository Pacman personalizzato per Arch Linux oppure l'installazione universale con Node.js su qualsiasi sistema operativo.

Opzione 1: Repository Pacman Ufficiale (Arch / Manjaro) 
# 1. Aggiungi il repository a /etc/pacman.conf:
sudo bash -c 'cat <<EOF >> /etc/pacman.conf

[manga-cli]
SigLevel = Optional TrustAll
Server = https://bhaki18.github.io/manga-cli/\$arch
EOF'

# 2. Sincronizza i repository e installa:
sudo pacman -Sy manga-cli

# 3. Avvia il client interattivo:
manga-cli
# oppure in modalità anime:
anime-cli
Opzione 2: Installazione Universale con Node.js (v18+) 
# Clona e collega globalmente via npm:
git clone https://github.com/bhaki18/manga-cli.git
cd manga-cli
npm install
sudo npm link

# Ora puoi invocare i comandi ovunque:
manga-cli "one piece" --lang it
anime-cli "demon slayer" --dub
