Ubuntu, Debian, Linux Mint & derivatives (.deb)

The ready-to-run package for your computer: download it and double-click to install in seconds!

Download .deb Installer (Latest)
Or install with a single terminal command: 
# Download and install the app in one command:
curl -LO https://bhaki18.github.io/manga-cli/deb/manga-gui_latest_amd64.deb
sudo apt install ./manga-gui_*_amd64.deb

# Then start the app (you can also find it in your application menu):
manga-gui

Arch Linux, Manjaro, EndeavourOS

Add the official repository to receive future updates alongside your regular system packages with a simple command.

Step 1: Enable the official repository 
# Copy and paste this block into your terminal:
sudo bash -c 'cat <<EOF >> /etc/pacman.conf

[manga-cli]
SigLevel = Optional TrustAll
Server = https://bhaki18.github.io/manga-cli/\$arch
EOF'
Step 2: Install via Pacman 
# Install both the desktop app and the terminal command:
sudo pacman -Sy manga-gui manga-cli

Fedora, openSUSE & Other Linux Distributions

The universal automatic installer takes care of everything: it detects your Linux distro, configures all requirements, and adds the launcher icon to your desktop menu.

Universal Automatic Installer 
# Download and run the automated installer:
git clone https://github.com/bhaki18/manga-gui.git
cd manga-gui
sudo ./install.sh

Manga & Anime from Terminal

Everything you need to search and stream anime or read manga directly from your keyboard.

Universal Install via Node.js 
# Download and link the command on your system:
git clone https://github.com/bhaki18/manga-cli.git
cd manga-cli
npm install && sudo npm link

# Now simply type the title you want to watch or read:
manga-cli "one piece"
anime-cli "demon slayer"
