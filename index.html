Installazione Alla Portata di Tutti

Come installare sul tuo sistema

Seleziona il tuo sistema operativo e segui la procedura in un solo passaggio.

Installare su Smartphone o Tablet Android

Non serve passare dal Play Store. L'app è sicura, gratuita al 100% e si aggiorna da sola ogni volta che esce una novità!

  1. Premi il pulsante arancione Scarica APK Diretto qui sotto.
  2. Se il tuo telefono ti chiede conferma, tocca Scarica comunque.
  3. Apri il file appena scaricato e tocca Installa (se richiesto, abilita Consenti l'installazione da questa sorgente).
  4. Apri l'app e cerca subito i tuoi manga o anime preferiti!
Scarica APK per Android (v1.0.9)

Sei al Computer?

Inquadra questo codice con la fotocamera del tuo telefono per scaricare subito l'app.

Ubuntu, Debian, Linux Mint e derivate (.deb)

Il pacchetto già pronto per il tuo computer: basta scaricarlo e fare doppio click per iniziare subito!

Scarica File di Installazione .deb (v1.1.4-1)
Oppure installa con un click copiando questo comando: 
# Scarica e installa l'app in un colpo solo:
curl -LO https://bhaki18.github.io/manga-cli/deb/manga-gui_1.1.4-1_amd64.deb
sudo apt install ./manga-gui_1.1.4-1_amd64.deb

# Poi avvia l'app (la trovi anche nel menu delle applicazioni):
manga-gui

Arch Linux, Manjaro, EndeavourOS

Aggiungi il repository ufficiale: così riceverai tutti gli aggiornamenti futuri insieme a quelli del tuo sistema con un semplice comando.

Passo 1: Abilita il repository ufficiale 
# Copia e incolla questo comando nel tuo terminale:
sudo bash -c 'cat <<EOF >> /etc/pacman.conf

[manga-cli]
SigLevel = Optional TrustAll
Server = https://bhaki18.github.io/manga-cli/\$arch
EOF'
Passo 2: Installa l'applicazione 
# Installa sia l'app grafica che il comando rapido da terminale:
sudo pacman -Sy manga-gui manga-cli

Fedora, openSUSE e Altri Sistemi Linux

C'è un installatore automatico che pensa a tutto lui: riconosce la tua versione di Linux, prepara le cose necessarie e aggiunge l'icona nel tuo menu.

Installatore Automatico Universale 
# Scarica ed esegui l'installatore automatico:
git clone https://github.com/bhaki18/manga-gui.git
cd manga-gui
sudo ./install.sh

Manga & Anime da Riga di Comando

Tutto quello che ti serve per guardare anime e leggere manga direttamente dalla tastiera in un lampo.

Installazione Semplice via Node.js 
# Scarica e attiva il comando sul tuo computer:
git clone https://github.com/bhaki18/manga-cli.git
cd manga-cli
npm install && sudo npm link

# Ora ti basta digitare il nome di un manga o anime:
manga-cli "one piece"
anime-cli "demon slayer"
